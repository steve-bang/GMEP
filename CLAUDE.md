## Project

GMEP is a Garage Management ERP Platform: a web application that replaces the Excel-based management of a client who owns a chain of auto garages across Vietnam. The goal is a single web system covering all garage operations:

- Processes / workflows and job (work order) tracking
- Labor / staff
- Inventory (warehouse) and spare parts
- Customers
- Revenue and accounting
- Invoicing customers

The client operates multiple branches nationwide, so multi-branch support (per-branch inventory, staff, revenue, with consolidated reporting for the owner) is a core requirement. Domain language is Vietnamese (the user and client communicate in Vietnamese), so expect Vietnamese UI text, currency (VND), and Vietnamese invoicing/accounting conventions.
